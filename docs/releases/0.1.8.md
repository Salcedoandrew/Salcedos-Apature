# Release 0.1.8

## Contents

- Revisiting a folder is faster: a cached thumbnail no longer makes Apature scan
  the photo again for its largest embedded preview.
- A background worker that cannot start now says why in the log instead of
  closing the window.

## Steps

1. Version-bump commit on main: Cargo.toml, Cargo.lock, CHANGELOG.md, this file.
2. Tag v0.1.8 on the bump commit; the release workflow builds and attaches the DMG.
3. Verify the release page shows Apature-0.1.7.dmg and its SHA-256.
4. Download the DMG and launch it once on a Mac that did not build it.

## Notes

- The v0.1.7 tag build failed in the macOS compiler and published
  nothing; 0.1.8 is the same contents built correctly. The tag is inert.
- Ad-hoc signed (no Developer ID secrets on this fork); first launch needs
  right-click Open.
- Step 4 is outstanding: this cut was made away from a Mac.
