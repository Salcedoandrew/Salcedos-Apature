# Apature 0.2.1

A bug-fix release. There are no new features.

## Fixed
- **Large folders no longer beachball.** Sidecar paths are resolved from the folder scan's own listing instead of re-listing the directory on every frame, and the inspector no longer touches the filesystem to show sidecar state. Folders with thousands of photos, such as a 4,233-photo wedding folder, open and browse without locking up the app.
