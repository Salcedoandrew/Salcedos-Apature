# Release 0.1.13

## Contents

- A photo whose file carries no EXIF at all now says so in the inspector instead
  of sitting on "reading…". The summary is read once for every file when the
  folder opens and nothing appends files later, so an empty result means the
  file has none, and the panel now reads "No EXIF in this file".
- The screenshot published beside each release now shows a small sample shoot
  instead of an empty folder, so the sheet, its thumbnails and the filmstrip are
  visible doing their job.

## Steps

1. Version-bump commit on main: Cargo.toml, Cargo.lock, CHANGELOG.md, this file.
2. Tag v0.1.13 on the bump commit; the release workflow builds and attaches the DMG.
3. Verify the release page shows Apature-0.1.13.dmg and its SHA-256 (REL-22).
4. Dispatch the screenshot workflow for v0.1.13 and check the PNG on the release page (REL-30).
5. Download the DMG and launch it once on a Mac that did not build it.

## Notes

- Small release: the inspector wording fix and the sample shoot behind the
  published screenshot. Nothing in ingest, export, metadata writing, delivery or
  the updater changed.
- The disk image is ad-hoc signed when the Developer ID secrets are absent; the
  first launch then needs right-click Open.
- Step 5 needs a Mac. This release was cut away from one, so the first launch is
  still to be done.
