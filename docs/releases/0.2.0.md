# Apature 0.2.0

## Added
- **Subfolders when you ask for them.** The folder strip has an Include subfolders checkbox. Turn it on and the contact sheet also shows the photos inside the selected folder's subfolders. It is off by default and Apature remembers the choice between launches.
- **TIFF and PNG in the contact sheet.** Both formats now sit beside RAW and JPEG, so they can be browsed, marked and captioned like any other picture. Their previews come from at most 2048 pixels on the long side, so a large scan is not held in memory just to fill a cell.
- **TIFF and PNG exports keep their format.** A TIFF goes back out as a TIFF and a PNG as a PNG, decoded from the whole file rather than the reduced preview, so full resolution comes back with crop, rotate and resize applied as they are to JPEG.
- **Bit depth and alpha survive.** A TIFF export keeps its bit depth and a PNG export keeps its alpha channel.
- **Metadata lands in the file.** An exported PNG carries its metadata in an eXIf chunk and an XMP iTXt block; an exported TIFF carries an EXIF directory along with the XMP and IPTC fields a TIFF can hold.

## Changed
- **A quieter sidebar.** It now shows Favorites and Folders only. Apature still reopens the last folder on launch, but the Recent list is gone.
- **An image-only contact sheet.** It lists RAW, JPEG, TIFF and PNG, and leaves sidecars, text files and videos out.
- **HEIC is not listed.** The preview decoder has no HEIC support, so those files no longer appear in the sheet. Ingest still copies them from a card.

## Maintenance
- **CI asks for less.** The workflow now runs with read-only token access by default, and grants check-run writing only to the dependency audit job that needs it.
