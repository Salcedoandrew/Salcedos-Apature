# Apature 0.1.15

## Added
- **Compressed previews on the way out.** Extract JPEG Previews has a new Compress extracted JPEGs box. Turn it on and each extracted JPEG is written again at the Alic image compressor's JPEG quality, 80 unless you change the number beside the box, so the files arrive already the size an Alic pass would leave them. Exif, IPTC/XMP, the ICC profile and the capture date still come across exactly as they did before.
