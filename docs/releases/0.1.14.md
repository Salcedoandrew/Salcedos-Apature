# Apature 0.1.14

## Fixed
- **No more repeat update offers.** Release builds are stamped as releases, so the updater stops offering the version already installed.
- **ExFAT copies keep going.** If an ExFAT drive can't set a file's dates, the copy is kept with a warning instead of failing. The flush fallback is now covered by tests, and copy errors name the failing step.
