# Release 0.1.4

## Contents

- Thumbnail cache warm-up: the contact sheet now queues the rest of the
  folder into the persistent disk cache in the background, at a lower
  priority than visible rows and previews, so scrolling a big folder on a
  slow drive re-decodes from the local cache instead of the originals.
  Merged from PR #3 (squash commit 7c0da7b64747c1d5ea0a04d22e8c017f1ee8ef03).

## Steps

1. Version-bump commit on main: Cargo.toml, Cargo.lock, CHANGELOG.md, this file.
2. Tag v0.1.4 on the bump commit. The release workflow builds the DMG on a
   macOS runner, computes its SHA-256, and attaches both to the release.
3. Verify the release page shows Apature-0.1.4.dmg and its SHA-256.
4. Download the DMG and launch it once on a Mac that did not build it.
