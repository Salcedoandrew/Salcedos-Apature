# Release 0.1.5

## Contents

- Clearing the thumbnail cache now clears it for real. The photos on screen are
  read again from their files and the background warm-up fills the new cache, so
  it does not stay empty until the folder is reopened.
- Warm-up no longer loses the work it queued. A photo counts as warmed only once
  its thumbnail actually arrives, so switching tabs or clearing the cache cannot
  leave part of a folder uncached for the rest of the session.

## Steps

1. Version-bump commit on main: Cargo.toml, Cargo.lock, CHANGELOG.md, this file.
2. Tag v0.1.5 on the bump commit. The release workflow builds the DMG on a macOS
   runner, computes its SHA-256, and attaches both to the release.
3. Verify the release page shows Apature-0.1.5.dmg and its SHA-256.
4. Download the DMG and launch it once on a Mac that did not build it.

## Notes

- Ad-hoc signed (no Developer ID secrets on this fork); first launch needs
  right-click Open.
- Step 4 was not done before the tag: these fixes were made away from a Mac.
  The desktop crate was type checked on Linux with the same GTK libraries CI
  installs, and the macOS check job runs on the pull request before the merge.
