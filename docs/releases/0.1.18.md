# Apature 0.1.18

## Fixed
- **A broken photo no longer stalls the queue.** A photo that breaks the decoder is marked as failed and its worker thread carries on with the next one.
- **Silent failures now speak up.** Settings, the delivery list and the list of already-imported photos log a message when they cannot be saved or read, instead of failing silently.
- **Impossible JPEG sizes are refused.** A JPEG header claiming an impossible size is turned away before decoding, instead of asking the machine for gigabytes of memory.
- **Interrupted renames say what they could not undo.** A rename that gets interrupted halfway now names the files the rollback could not put back.
- **Impossible dates are ignored, not shifted.** A date such as 31 February is ignored instead of being silently turned into 3 March.
- **The copy summary shows partial date warnings.** The summary now says how many files kept their dates only in part, instead of hiding the warnings in the log.
- **Two vulnerable libraries updated.** Delivery over FTP no longer uses a client library with a known command-injection flaw, and a compression library with a build-script leak is updated.

## Changed
- **Releases now fail on vulnerable dependencies.** The release checks include a dependency audit, so a library with a known vulnerability fails the build before it ships.
